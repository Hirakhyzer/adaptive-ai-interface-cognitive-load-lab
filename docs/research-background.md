# Research Background

Adaptive AI interfaces are interactive systems that change presentation, explanation, or support behaviour according to task context and user needs. In HCI research, this topic connects cognitive load, attention management, explainable AI, usability evaluation, and human autonomy.

## Problem

Many digital systems assume that every user benefits from the same amount of information at the same time. This can create overload when tasks are complex, time-sensitive, unfamiliar, or interruption-heavy.

## Research opportunity

A cognitive-load-aware interface can make interface behaviour more responsive. However, adaptation must be transparent and user-controllable. A system that hides information or silently changes behaviour can reduce trust, agency, and accountability.

## Design position

This project treats adaptation as support, not control. It explores how explanation depth, notification timing, visual density, and guidance can change while preserving user choice.

## Relevant HCI themes

- Cognitive load and mental workload.
- Attention-aware interface design.
- Human-centered explainable AI.
- Adaptive user interfaces.
- Usability and trust evaluation.
- Responsible AI and user autonomy.
