# Ethical Boundary

This repository is an academic HCI prototype for synthetic research and education.

## What this project is

- A research scaffold for adaptive interface design.
- A transparent demonstration of load-aware interface policies.
- A teaching resource for human-centered AI and usability evaluation.
- A starting point for controlled, consent-based HCI study design.

## What this project is not

- A clinical assessment tool.
- A mental-state diagnosis tool.
- A real user-tracking product.
- A worker evaluation system.
- A deployment-ready adaptive interface.

## Responsible-use principles

- Use synthetic data unless an approved study protocol exists.
- Tell participants what signals are used and why.
- Allow inspection, override, and opt-out.
- Avoid hidden scoring or ranking of users.
- Preserve user autonomy and dignity.
- Report limitations clearly.
