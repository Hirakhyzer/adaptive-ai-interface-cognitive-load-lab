# Evaluation Methodology

The project can be evaluated as a controlled HCI study comparing static and adaptive interface conditions.

## Conditions

| Condition | Description |
|---|---|
| Static interface | Same information density, explanation depth, and notification behaviour for all tasks. |
| Adaptive interface | Interface mode changes according to task context and synthetic signals. |

## Example metrics

| Metric | Purpose |
|---|---|
| Task completion time | Measures efficiency. |
| Error rate | Measures outcome quality. |
| Perceived workload | Captures user-reported burden. |
| Trust rating | Captures perceived reliability and understandability. |
| Explanation usefulness | Captures whether explanations helped the task. |
| Autonomy rating | Captures whether users felt in control. |
| Interruption count | Captures disruption from prompts or alerts. |

## Suggested analysis

- Compare static and adaptive conditions.
- Report descriptive statistics and confidence intervals.
- Inspect qualitative comments about transparency and control.
- Treat results as interface-design evidence, not as claims about real mental states.
