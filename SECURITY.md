# Security and Responsible Use

This repository is a synthetic HCI research prototype.

## Reporting concerns

Open an issue if you find a problem in the prototype logic, documentation, tests, or responsible-use boundary.

## Not supported

The project does not support covert data collection, hidden interface manipulation, real-user tracking, clinical assessment, workplace productivity scoring, or deployment without review.

## Principle

Adaptive AI interfaces should increase clarity and support while preserving user autonomy, transparency, and consent.
